# FSM-spec-v1 (Quest SoundPro SE-DL R.13J)

Finite State Machine specification based on Menu & Screen Reference v2.5. Defines states, events, transitions, and guards for the simulator. Includes incremental build plan and test matrix.

**Usage:** Import into Cursor's /docs or /planning directory as the main logic source for implementation. Cross-reference state IDs with asset filenames (e.g., slm_home_page1_running.jpeg).
