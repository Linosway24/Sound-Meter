# SLM training photos

Documentary images for the Sound Level Meter instructional project.

## Current Overview images

- `aircraft-sheet-metal-repair-hearing-protection.jpeg` — Airmen repairing aircraft sheet metal with a pneumatic tool while wearing hearing protection.
- `flight-line-hearing-protection.jpeg` — Airman fitting hearing protection on a flight line near an aircraft.
- `industrial-angle-grinding-hearing-protection.jpg` — industrial worker using an angle grinder while wearing eye and hearing protection.

## Retained for later use

- `abrasive-blasting-cabinet-operator-hearing-protection.png` — operator using an abrasive-blasting cabinet while wearing hearing protection.
- `angle-grinding-metal-sparks-face-shield.png` — operator grinding metal with a face shield as sparks cross the worktable.
- `sheet-metal-shear-operator-hearing-protection.png` — operator positioning sheet metal at a powered shear while wearing hearing protection.

The retained project copies were produced non-destructively with restrained color, exposure, noise, and sharpness corrections. Their original screenshots remain on the Desktop.
